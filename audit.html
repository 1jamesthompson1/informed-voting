How to read the matrix

+2 strongly supports · +1 supports · 0 mixed or conditional · −1 opposes · −2 strongly opposes · – no clear published position. A dash is not a score of zero. “Official” sources are the party’s own 2026 material; “secondary” sources are established news or policy analysis used only where the official material was not specific enough. Every position is a snapshot as at 4 November 2026.

✎
Found an error?

Policy coding is a human judgement. If a source is wrong, out of date, or missing important context, please open an issue on the project’s GitHub repository with the statement ID, the party, and the source you believe is correct. Corrections will be logged on the methods page. This project is not affiliated with any party.
